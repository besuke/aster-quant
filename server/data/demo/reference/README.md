# 発行体マスタ（デモ・架空）

レポートとオファーを発行体単位で結びつけるための、架空の発行体マスタ。Curie のデモの銘柄属性は発行体名がすべて
「架空発行体（テスト用）」で区別がないので、QuantLet のデモ用に別ファイルで用意した（A1 の計算の入力は変えていない）。

- `issuer_master.csv`：発行体ID、正式名、別名（`;` 区切り。レポート中の呼び方との照合に使う）
- `isin_issuer.csv`：ISIN → 発行体ID

本番では Aladdin などの発行体ID体系に置き換える（Curie の開発計画 A3 で「発行体IDの体系は未定」とされている）。
XYZホールディングスと XYZ銀行は、名前の一部（XYZ）が共通の別の発行体で、曖昧な呼び方（「XYZ」）の候補表示を確かめるためのもの。
